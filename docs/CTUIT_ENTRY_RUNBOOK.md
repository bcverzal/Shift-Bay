# Ctuit Entry Runbook

Use Shift Bay's `Ctuit entry list` print for every schedule. It is the source of truth for employee, role, time, training notes, and closer state.

1. Review the Entry Preflight at the top of the print. Enter the direct rows first.
2. For every Ctuit time field, select all existing text, clear it, then type the padded time and `a` or `p`. Example: `09:00a`, `04:30p`.
3. For every row, apply the printed close instruction. `Close: Clear` is an action: Ctuit can retain this flag from a template row.
4. Use `Show More` for any shift longer than eight hours or any until-volume shift. Ctuit otherwise hides eligible employees.
5. If Ctuit does not show an employee for their intended role, first edit the row to a role where they appear, select the employee and save. Reopen the row, change it to the intended role, and save again.
6. Use the yellow-pencil editor for name selection when possible; its alphabetical list is faster to scan than the blue staff picker.
7. After entry, verify only the exception rows and any unmatched names or roles. Do not post until the Shift Bay and Ctuit rows agree.

## Expected Timing

- Direct-entry batch: 45-75 minutes for a typical 100-shift week.
- Exceptions and verification: 30-60 minutes, depending on missing Ctuit role visibility and template edits.

The target is a reliable 1.5-2 hour workflow. Any recurring exception should be captured in the Ctuit employee/role mapping rather than rediscovered next week.
