# Shift Bay Demo Data

This folder contains sanitized fake data for reviewing Shift Bay without using Brian's real employee or schedule data.

## Load the demo

1. Start Shift Bay.
2. Open **Settings**.
3. In **Imports & Data**, use **Restore**.
4. Choose `demo-data/shift-bay-demo-data.json`.

The demo includes fake employees, availability, grouped roles, assigned shifts, open Shift Bay shifts, request-offs, a day block, training notes, closers, a flex double, projections, coverage requirements, templates, and floor-plan settings.

## Important

Restoring this file replaces the currently loaded browser/server scheduler data. Back up real data first before loading the demo in a working environment.
